📖 玩法说明

① 选模特：共 6 位，每人带不同皮肤问题（痘印/雀斑/黑眼圈/毛孔/红痘/晒斑）。

② 选化妆品：粉底 / 遮瑕 / 散粉 / 腮红 / 修容 / 高光 / 眼影 / 眼线 / 眉笔 / 睫毛 / 口红 / 唇蜜 / 卸妆 / 淡化（14 类）。

③ 换刷具：每种化妆品配多种专业刷具，影响覆盖力和范围。

④ 调色 + 调笔刷 + 调浓淡：下方滑杆可自由调整。

🎯 精准涂抹（默认开启）：腮红只涂脸颊、眼影只涂眼皮、口红只涂嘴唇，完全不遮挡五官。关闭后可全脸自由涂抹。

➖➕ 放大缩小：50% ~ 300%，双击画布一键还原；PC 端鼠标滚轮快速缩放；移动端可拖动画面。

☁️ 淡化工具 / 柔化棉：轻微擦掉妆容浓度，不会一下抹干净，修重手非常好用。

↩️ 撤销 / 🧽 全卸妆：放心大胆画，随时重来。
